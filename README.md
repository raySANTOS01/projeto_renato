Landing page estática, responsiva e pronta para Vercel.

## Estrutura
- `index.html` — página completa
- `styles.css` — visual, responsividade e animações
- `script.js` — WhatsApp, formulário, scroll reveal e barra de progresso

## Publicar na Vercel
1. Crie um repositório no GitHub e envie estes arquivos para a raiz.
2. Em Vercel, importe o repositório.
3. Framework: `Other`.
4. Build Command: deixe vazio.
5. Output Directory: `.`
6. Deploy.

Também é possível usar a opção de importar um projeto estático pela interface da Vercel.
